Loudness and mastering

See it in action: Measure and set loudness · Mixing: inserts, buses, sends, sidechain, mastering

Loudness measurement (loudness.hpp)

measure_loudness(buf, sr) implements ITU-R BS.1770 / EBU R128-style metering with K-weighting (high shelf +4 dB at 1.68 kHz, then 38 Hz RLB high-pass) and returns LoudnessReport:

FieldMeaning
validFalse if shorter than one 400 ms block or fully gated out
integrated_lufsGated programme loudness
momentary_max_lufsLoudest 400 ms
short_term_max_lufsLoudest 3 s
loudness_range_luLRA (10th–95th percentile of gated short-term values)
sample_peak_dbdBFS
true_peak_dbdBTP, 4× oversampled

normalize_loudness(buf, sr, target_lufs, ceiling_dbtp = −1, limit = true) applies gain to reach the target; if the true peak would exceed the ceiling it uses a lookahead limiter (limit = true) or reduces the gain (limit = false). Length is unchanged; the post-processing report is returned.

Mastering (master.hpp)

MasterSettings: preset (MasterPreset { Clean, Warm, Club, Loud, Gentle, LoFi }), target_lufs −14, ceiling_dbtp −1, glue 1 (bus compression amount), saturation 1, width 1, tilt_db 0, bass_mono true. MasterSettings::for_preset(p) sets the preset's target:

PresetTarget LUFSCharacter (from build_master_chain)
Clean−1422 Hz high-pass, glue compressor, imager
Warm−14+1.5 dB low shelf, −1 dB high shelf, tape saturation
Club−9Bass lift, presence and air, soft saturation, multiband compression, width 1.12
Loud−8Similar to Club with heavier multiband and drive
Gentle−16Light air shelf, lower compression ratio
LoFi−1660 Hz high-pass, 9.5 kHz low-pass, tape saturation, width 0.85, no bass-mono
  • build_master_chain(settings) returns the chain up to (not including) the loudness limiter: EQ → optional saturator → optional multiband compressor → glue compressor (RMS detector, 90 Hz detector high-pass) → stereo imager (mono below 120 Hz when bass_mono).
  • master(buf, sr, settings) masters in place to the target and returns MasterReport (before, after, gain_db, limiter_reduction_db, target_reached within 0.5 LU, iterations).
  • master_for_genre(name) returns starting settings by genre name, ignoring case, spaces and punctuation ("Drum & Bass", "drum_and_bass" and "dnb" all work); unknown names yield Clean at −14 LUFS. Targets: classical/ambient −18 (Gentle, reduced glue), jazz/bossa nova −16, blues −15, reggae −14, funk −13, chiptune −12 (Clean), rock −11, touhou −10, metal −9, house/trance −9, techno/dubstep/drum and bass −8 (Club), hardcore/speedcore −7 (Loud).

wauvio::fx::struct MasterSettings

struct MasterSettings
    MasterPreset preset = MasterPreset::Clean;
    double target_lufs  = -14.0;    ///< integrated loudness to reach
    double ceiling_dbtp = -1.0;     ///< true-peak ceiling
    double glue         = 1.0;      ///< 0 = no bus compression .. 1 = preset amount .. 2 = twice as much
    double saturation   = 1.0;      ///< 0 = off .. 1 = preset amount .. 2 = more
    double width        = 1.0;      ///< multiplies the preset's stereo width
    double tilt_db      = 0.0;      ///< + = brighter, - = darker (shelves around 300 Hz / 4 kHz)
    bool   bass_mono    = true;     ///< keep the lows centred (mono below ~120 Hz)
    /// Preset defaults, including a sensible loudness target for the style.
    static MasterSettings for_preset(MasterPreset p)
