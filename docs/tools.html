Overview

Tools

Programs and scripts that ship inside the library for auditioning content and regenerating code. All C++ tools build the same way (header-only library, no extra dependencies):

g++ -std=c++17 -O2 -I/path/to/wauvio-repo path/to/tool.cpp -o tool

Auditioning

ToolLocationWhat it does
render_instrumentswauvio/ext/tools/render_instruments.cppWrites one audition WAV per instrument (and per drum kit) plus index.csv, so you can listen to the catalog one by one. Each file is a fixed dry sequence: C3, C4 and C5 at mf, C4 at pp and ff, a C-major scale, then one note per supported articulation (drums: a hit per dynamic and note). Options: --out DIR (default instrument_audition), --only TEXT (family, class or name contains TEXT, e.g. --only brass), --normalize (off by default so loudness differences stay audible), --split (also one file per segment), --list, --no-kits
render_genreswauvio/midi/tools/render_genres.cppRenders one MIDI file in every genre preset (or a chosen few) so genres can be compared by ear. ./render_genres song.mid [--out DIR] [--only TEXT] [--strength S] [--no-instruments] [--seed N] [--list]. Output: DIR/<family>/<Genre>.wav plus DIR/original.wav. --only matches name, alias or family (--only metal, --only latin); --strength applies each genre at 0–1; --no-instruments keeps the song’s own instruments and kit
wauvio_sfx_toolwauvio/sfx/tools/wauvio_sfx_tool.cppList, search and render SFX presets. See SFX tool
sing_score, listen, selfcheck, locus_probe, vc_probewauvio/vocal/yune-v*/tools/Vocal score renderer, A/B demos, behaviour checks and analysis. See Vocal tools
compose examplewauvio/compose/examples/compose.cppA quick draft, a jazz song with MIDI and mastering, and a song from a .wcp file. See Compose tools

Generators (for contributors)

Some headers are generated from tables. Edit the table, re-run the script, and rebuild. Generated files say so in their first lines; do not edit them by hand.
