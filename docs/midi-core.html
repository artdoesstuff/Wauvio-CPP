MIDI layer (wauvio/midi)

MIDI file model

Headers in wauvio/midi/core/, namespace wauvio::midi.

  • ByteReader — bounds-checked big-endian reader over a byte array: u8, u16be, u32be, read_vlq (variable-length quantity), skip, seek, eof, remaining, position, ptr. Reading past the end throws MidiParseError (derives std::runtime_error).
  • MidiEventType — NoteOff, NoteOn, PolyAftertouch, ControlChange, ProgramChange, ChannelAftertouch, PitchBend, Meta, SysEx, Other.
  • MidiEvent — absolute tick, type, channel, data1/data2, meta_type, meta_data.
  • ParsedTrack (name, instrument_name, events) and ParsedMidiFile (format, declared_track_count, division (default 480), SMPTE fields, tracks).
  • TimeSignatureEvent, KeySignatureEvent — extracted meta events.
  • read_whole_file(path), parse_midi_file(path), parse_midi_bytes(bytes, label) — parse an SMF into a ParsedMidiFile.
  • TempoMap — add_tempo_event(tick, µs/quarter), then finalize(ticks_per_quarter) (or finalize_smpte(fps, ticks_per_frame)) builds segments; tick_to_seconds, seconds_to_ticks, bpm_at_start, tempo_events, ticks_per_quarter. Handles tempo changes and SMPTE time bases.

wauvio::midi::class ByteReader

class ByteReader
public:
    ByteReader(const unsigned char* data, size_t size) : data_(data), size_(size) {}
    bool eof() const noexcept { return pos_ >= size_; }
    size_t remaining() const noexcept { return pos_ < size_ ? size_ - pos_ : 0; }
    size_t position() const noexcept { return pos_; }
    void require(size_t n) const
    uint8_t u8()
    uint16_t u16be()
    uint32_t u32be()
    void skip(size_t n)
    void seek(size_t absolute_pos)
    uint32_t read_vlq()
    const unsigned char* ptr() const noexcept { return data_ + pos_; }
