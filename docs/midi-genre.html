MIDI layer (wauvio/midi)

MIDI genre system

Headers midi/genre/genre_midi.hpp and genre_midi_presets.hpp, namespace wauvio::midi::genre. It wraps the music-layer genre presets and applies them to a loaded MidiMusic.

See it in action: Restyle with a genre

Types

  • MidiGenrePreset — wraps a base GenrePresetPtr and adds melodic_program_overrides (GM program → factory) and an optional percussion_kit factory. name() returns the base name. MidiGenrePresetPtr is shared_ptr<const MidiGenrePreset>.
  • GenreApplyOptions — allow_instrumentation (false: only restyle notes/FX, do not swap instruments), override_explicit_programs (false: keep programs set in the file), seed (1; all variation is deterministic).

What setGenre does

  1. First call stores a pristine copy of the parts and each instrument’s style baseline, so the operation is reversible. Every call restarts from that baseline, so calling setGenre twice never compounds.
  2. Each part gets a role: percussion part → Percussion; GM programs 32–39 → Bass; otherwise Melodic (role_for_part).
  3. apply_role_profile processes every note: optional thinning of soft notes, register shift, forced articulation (shortening the note by fallback_gate_ratio if the instrument lacks it), gate_ratio shortening, quantisation to a beat fraction, swing (on eighths, or sixteenths with swing_subdivision = 4), per-16th groove_timing, fixed timing offset, humanisation, then dynamics (velocity scale, per-beat accent pattern, downbeat de-emphasis, groove_velocity, velocity_compress, variance) clamped between velocity_floor and 1. The file’s own tempo is used, so all timing rules apply here.
  4. If allow_instrumentation is set, unpinned parts get preset instruments/drum kit (skipping parts whose program came from the file unless override_explicit_programs).
  5. Instruments are restyled with the preset’s timbre/FX wants (style_instrument, and style_percussion_kit for kits).

Beat length and beats per bar are estimated from the file (estimate_beat_seconds, estimate_beats_per_bar). clearGenre() restores the pristine state.

Finding and weakening genres

The MIDI registry (midi/genre/genre_midi_registry.hpp, generated by gen_genres.py) has the same genres and names as the music-layer registry, but each result also carries its drum kit and instrument choices.

auto jazz = wauvio::midi::genre::find("jazz");              // loose name matching and aliases; nullptr if unknown
music.setGenre(jazz);
music.setGenre(wauvio::midi::genre::with_strength(jazz, 0.5));   // half-way between the original and the genre
  • find(name) — a genre looked up by name or alias (case, spaces and punctuation ignored). A preset you added to the music-layer registry without a MIDI counterpart is returned with just its base profile.
  • all() — every genre, in the music-layer registry’s order.
  • with_strength(preset, s) — the same genre at a fraction of its strength (1 = unchanged, 0 = none). Kit and instrument choices are kept at 0.5 and above, dropped below.

Presets

All genres in the built-in list are available. The original eighteen also exist as midi::genre::presets::classical(), jazz(), rock(), metal(), house(), techno(), drum_and_bass(), chiptune(), ambient(), touhou(), funk(), blues(), reggae(), trance(), dubstep(), bossa_nova(), hardcore() and speedcore(), with program overrides and kits (for example metal() maps programs 26, 27 and 29 to DistortedElectricGuitar and uses IndustrialKit); the rest are in genre_midi_presets_extra.hpp.

Audition every genre: render_genres

wauvio/midi/tools/render_genres.cpp renders one MIDI file in every genre (or a chosen few) so you can compare them by ear. See Tools.
