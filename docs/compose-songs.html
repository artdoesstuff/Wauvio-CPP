Compose engine (wauvio/compose)

Composer, sections and songs

Header compose/arrangement/song.hpp. The Composer is a fluent builder around ComposeConfig; compose() returns a ComposedSong.

See it in action: The Composer · Song structure

Shortcuts: compose_draft(root, scale, bpm, mood, bars, seed) and compose_from_wcp(path, prog, motif, mood, seed).

Sections

A SectionSpec has role (SectionRole: Intro, Verse, PreChorus, Chorus, Bridge, Breakdown, Outro), name, bars (4), energy 0–1 (0.6; busier and louder when higher), its own progression and motif, and switches enable_melody, enable_chords, enable_bass, enable_drums (all true) and enable_counter (false). If you add none, the default structure is six sections of four bars: Intro (chords and bass), Verse 1, Chorus 1 (with countermelody), Verse 2, Chorus 2, Outro. With quick_draft(n) it is one “Draft” section of n bars at energy 0.75.

ComposedSong

  • config (the resolved ComposeConfig), sections (ComposedSection: spec, start_sec, duration_sec, chords, melody, bass, accompaniment, counter), and arrangement (a normal music::Arrangement).
  • total_duration_seconds(), render(sample_rate, RenderOptions) → StereoBuffer, save(wav_path, RenderOptions), summary() (a readable description: key, tempo, sections and chords).
  • The song owns its instruments (owned_instruments, owned_kit), so it is safe to return and keep. The drum parts use DrumKitInstrument, an Instrument adapter around a DrumKit.
  • Because the arrangement is ordinary, you can add tracks, change gains, or hand it to fx::mixer_from_arrangement before rendering.

class Composer
public:
    Composer() = default;
    explicit Composer(ComposeConfig cfg) : cfg_(std::move(cfg)) {}
    Composer& key(PitchClass root, ScaleType scale = ScaleType::Major) { cfg_.key = Key(root, scale); return *this; }
    Composer& tempo(double bpm) { cfg_.bpm = bpm; return *this; }
    Composer& meter(int beats_per_bar, int beat_unit = 4) { cfg_.meter = Meter{ beats_per_bar, beat_unit }; return *this; }
    Composer& mood(Mood m) { cfg_.mood = m; return *this; }
    Composer& genre(const std::string& g, double strength = 0.7) { cfg_.genre = g; cfg_.genre_strength = strength; return *this; }
    Composer& seed(uint64_t s) { cfg_.seed = s; return *this; }
    Composer& quick_draft(int bars = 8) { cfg_.quick_bars = bars; return *this; }
    Composer& progression(ChordProgression p) { cfg_.progression = std::move(p); return *this; }
    Composer& progression(const std::string& name)
    Composer& motif(Motif m) { cfg_.motif = std::move(m); return *this; }
    Composer& motif(const std::string& name)
    Composer& accompaniment(AccompanimentPattern p) { cfg_.accompaniment = p; return *this; }
    Composer& bass_pattern(BassPattern p) { cfg_.bass_pattern = p; return *this; }
    Composer& drum_pattern(DrumPattern p) { cfg_.drum_pattern = p; return *this; }
