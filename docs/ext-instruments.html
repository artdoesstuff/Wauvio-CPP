Music layer (wauvio/ext)

Instrument catalog

All classes are in namespace wauvio::instruments and are default-constructible (instruments::Trumpet t;). Each sets up a TimbreRecipe in its constructor; tweak t.recipe or use the chainable FX setters afterwards. The tables list class, display name and family base class. Files named *_extra.hpp hold the later additions to each family; ext.hpp includes them all. A machine-readable list is in wauvio/ext/tools/instrument_catalog.hpp (see Tools).
