Vocal engine (wauvio/vocal)

Vocal tools

Command-line programs shipped beside each engine generation (vocal/yune-vN/tools/). All are single-file programs; build with g++ -std=c++17 -O2 -I<repo root> file.cpp -o name (add -pthread if needed).

See it in action: Text score for the sing_score tool

sing_score (v1, v2, v3)

Renders a text score or a MIDI file. Usage (v3): sing_score score.txt|song.mid out.wav [--voice id|file.wvc] [--dump timeline.csv] [--check]. Score commands, one per line, # for comments:

CommandMeaning
voice yune|path.wvcFirst line: which character sings
tempo BPM, rest TICKS
style NAME VALUEAny Style field (style devoicing off)
persona NAME [AMOUNT], persona_blend A B TDefault look
persona_lane NAME t:v;…, lane NAME t:v;…Absolute seconds; lane pitch = semitones
seed N, humanize [TIMING PITCH LENGTH BIAS TAKE], auto_expression [on|off]
natural [AMOUNT [TAKE]]A singer starts at the voice’s own natural amount with auto-expression on; natural 0 + auto_expression off = perfectly even delivery
arc KIND T0 T1 [DEPTH]Phrase arc
note MIDI TICKS LYRIC [VEL] [extras]Lyric may be {k a n a}
event KIND MIDI SECONDS [INTENSITY] [VARIANT]
say "TEXT" SECONDS [KIND] [MIDI] [accent=N]Speech
accent_height STDefault 3 semitones
parse particles on|off
double N(v3) N doubled takes of the lead
harmony SEMITONES [PAN [GAIN]](v3) transposed copy as a harmony part
chain natural|pop|intimate|hall(v3) finish with the vocal FX chain (stereo)

Note extras: vib=D,R,DELAY, porta=S, novib, stac, whisper, hum, orn=NAME[,DEPTH], persona=NAME[,AMOUNT], lane=NAME@t:v;t:v (seconds from note start), and NAME=VALUE for any Style field.

Other tools

ToolGenerationPurpose
voice_toolv2, v3list (built-in voices), export ID out.wvc, check file.wvc (typos are errors), demo ID|file.wvc out.wav, and gen [--check] [--force] [--root DIR] (pair voicebanks with voice headers and rebuild the registry; see Adding a voice). Uses tools/voice_gen.hpp
listenv2, v3Renders A/B listening demos for every feature into a folder of WAVs: listen [outdir=listen_out] [only-substring]; files are named NNN_area_name.wav
selfcheckv3Objective checks of v3 engine behaviour (plumbing and rules, including kanji conversion, not sound quality); exit code 0 = all passed. Intended to be built with sanitizers: -fsanitize=address,undefined
locus_probev3Reads the engine’s own F2/F3 control trajectory around consonant release and fits locus equations (F2_onset = slope × F2_vowel + intercept); locus_probe [voice-id|file.wvc] [offset_ms]
vc_probev3Reports how far F2 has moved toward a following consonant’s locus 8 ms and 3 ms before the vowel ends: vc_probe [voice-id|file.wvc]
