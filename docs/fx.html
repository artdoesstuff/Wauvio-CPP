FX suite (wauvio/fx)

FX suite overview

The FX suite (wauvio/fx.hpp, directory wauvio/fx/) is the full effects, mixing and mastering layer. It is separate from the small wauvio::fx::basic effects in the core. Everything is in namespace wauvio::fx.

Entry points

HeaderIncludesUse when
wauvio/fx.hppcore + all FX (common, Effect/Chain, EQ, dynamics, saturation, modulation, delay, stereo, FX I/O, reverb, loudness, master, mixer)Processing buffers; no music layer needed
wauvio/fx/ext.hppext.hpp + fx.hpp + mixer/from_arrangement.hppMixing a music::Arrangement
wauvio/fx/midi.hppext.hpp + midi.hpp + fx.hpp + from_arrangement.hpp + from_midi.hppMixing a MIDI file

Architecture

  • Every processor derives from Effect. Parameters are public fields re-read on each process() call.
  • Effects are ordered in a Chain, which handles latency compensation and tail extension automatically.
  • A Mixer combines sources, insert chains, buses, sends, sidechain ducking, a master chain and optional loudness mastering.
  • Mastering measures ITU-R BS.1770 loudness and drives a buffer to a LUFS target with a true-peak ceiling.

Pages

  • Effect base, Chain and DSP utilities
  • EQ and dynamics
  • Saturation and bitcrushing
  • Modulation, delay and stereo
  • Reverb
  • Loudness and mastering
  • Mixer and bridges

Example

#include "wauvio/fx/ext.hpp"        // fx.hpp + music layer + fx::write_wav
using namespace wauvio;

StereoBuffer mix = /* your audio */;
fx::Chain chain;
chain.add<fx::EQ>().highpass(30).peak(3000, 1.5);
auto& comp = chain.add<fx::Compressor>(); comp.threshold_db = -20; comp.ratio = 3;
chain.add<fx::FdnReverb>().mix = 0.15;
chain.process(mix, 44100);                  // latency removed, tail kept
fx::master(mix, 44100, fx::master_for_genre("house"));
fx::write_wav(mix, "out.wav");              // level-preserving writer (fx/ext.hpp)
