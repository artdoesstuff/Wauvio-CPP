Vocal engine (wauvio/vocal)

v3 — Voices, personas and voicebanks

VoiceModel

The identity of a voice: name, tune (engine gains), range_low/high (comfortable) and hard_low/high (absolute) as MIDI notes, five VowelTargets (F1–F3, bandwidths, gain, F0-tracking amounts), fixed upper formants f4–f6/b4–b6, singer’s formant (singer_formant_hz/_bw), glottal source (rd_base, aspiration, tilt_hz_min/max), vibrato defaults, synthetic (0–1: tighter bandwidths, steadier source, brighter uppers), consonant loci[4] (labial, alveolar, palatal, velar; F_locus = slope × F_vowel + intercept for F2 and F3, intercepts scaled by tract_scale()), and nasal parameters (nasal_zero_q, nasal_zero_depth, nasal_pole_hz, nasal_pole_gain, nasal_bw_widen). Tune holds out_scale 0.65, asp_gain 3, fric_gain 0.3, upper_gain 4.4, sing_gain 2.4, air_gain 0.1, pre_gain 1, f23_gain 30. Each singer owns its model, so rendering is thread-safe and voices can be tuned independently.

VoiceProfile

Everything that makes a character: id, display, language, notes, model, style (the “Normal” look), parse (lyric defaults), personas, natural_amount (recommended Singer::natural() strength).

Personas

A persona is a named, absolute “look” for the expressive Style fields (Persona {name, look}). A voice stays itself: its VoiceModel is untouched, persona values stay in a bounded envelope, and volume, velocity response, compression and devoicing are never changed. PersonaLibrary offers add, find, names, load(path), save(name, path, append). Text format: a persona NAME line followed by any Style field lines (others stay at the Normal look). Apply with apply_persona(lib, style, name, amount) or apply_persona_blend(lib, style, a, b, t, amount); blend_expressive() lerps only expressive fields (for vibrato fields where one side is -1 the explicit value wins). persona_morph_lanes() moves a note toward a persona over time using only fields that have a render channel (brightness, breathiness, tension, volume, growl, fry, air, register, formant shift, mouth opening).

Voicebank files (.wvc)

A voice can be exported to and loaded from a plain-text voicebank (save_profile, load_profile, profile_to_text, profile_from_text; extension VOICEBANK_EXT = .wvc; is_voicebank_path()). Loading starts from a copy of an existing voice so you can override a few values; unknown keys and malformed lines are errors, so typos are caught. Shipped banks are in yune-v3/voicebanks/.

class PersonaLibrary
public:
    PersonaLibrary() = default;     // empty; each voice (voices/voice-*.hpp) supplies its own personas
    void add(const std::string& name, const Style& look) { map_[name] = Persona{ name, look }; }
    const Persona* find(const std::string& name) const { auto it = map_.find(name); return it == map_.end() ? nullptr : &it->second; }
    std::vector<std::string> names() const { std::vector<std::string> v; for (auto& kv : map_) v.push_back(kv.first); return v; }
    // Text format (one persona per block):
    //   persona sweet
    //   brightness 0.78      # any Style field name, others stay at the Normal look
    // Returns the number of personas read.
    size_t load(const std::string& path)
    bool save(const std::string& name, const std::string& path, bool append = false) const
// Moves the expressive fields of `s` toward persona `name` by `amount` (0..1). Unknown names
// are ignored (returns false).
inline bool apply_persona(const PersonaLibrary& lib, Style& s, const std::string& name, float amount = 1.f)
// Blend of two personas (t = 0 -> a, 1 -> b), then moved toward by `amount`.

// Lanes that morph a note's current look toward persona `name` over time. `amount` is a
// curve of 0..1 vs seconds. Only fields that have a render-level channel can move inside a

// mouth opening. Values are converted into the channel's own units.
inline std::vector<Lane> persona_morph_lanes(const Style& cur, const Persona& p, const Curve& amount, double t_end, double t_begin = 0.0)
