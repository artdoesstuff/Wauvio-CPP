Compose engine (wauvio/compose)

The .wcp format

A Wauvio Compose Preset (.wcp) is a plain-text file of chord progressions and motifs. Use it to keep reusable harmonic and melodic ideas outside your code. Load with load_wcp(path, bank, &err) (or wcp_from_text), then pass the WcpBank to Composer::use_wcp(bank, progression_name, motif_name), or do it in one call with compose_from_wcp(path, prog, motif, mood, seed). save_wcp / wcp_to_text write one back. Errors come back as wcp line N: message and loading returns false.

See it in action: Your own chords and motifs (.wcp)

Syntax

One directive per line. # starts a comment (to end of line). Blank lines and a UTF-8 BOM are ignored.

Header (top level)

LineMeaning
name TEXT, author TEXTMetadata (quotes optional)
key ROOT [SCALE]e.g. key A minor, key Bb major, key E phrygian, key G blues. Root accepts sharps/flats. Scale names ignore case and punctuation: major (maj, ionian), minor (min, natural_minor, aeolian), harmonic_minor, melodic_minor, dorian, phrygian, lydian, mixolydian (mixo), pentatonic_major, pentatonic_minor, blues, whole_tone
bpm NGreater than 10 and at most 400
meter N/De.g. 4/4, 3/4. Sets the default chord length (one bar)
progression "NAME" … endA progression block
motif "NAME" … endA motif block

Inside progression

LineMeaning
chords | I:4 | vi:4 | IV:2 V7:2 |Roman-numeral tokens (syntax); | bar lines are optional; :N is beats, default one bar
tags a, bComma-separated
minor trueMarks a minor-leaning progression (1, true or yes)
description TEXT (or desc)

Inside motif

Write the notes either on one notes line or as parallel steps / dur / dyn lists.

LineMeaning
notes 0:0.75 2:0.75 c2:0.5 4:1.0@f r:0.5Each token is STEP[:BEATS][@DYNAMIC]. A number is a scale step (0 = tonic of the key); cN is the Nth chord tone (c0 = chord root); r (or .) is a rest
steps 4 3 2 r 0, dur 0.5 0.5 1.0 0.5 1.5, dyn mf mf mp mf pThe same information as separate lists (durations and dynamics are accepted too). If dur is shorter than steps, its last value repeats
tags, description

Dynamics are ppp pp p mp mf f ff fff. Durations must be greater than 0.

Complete example

# Wauvio Compose Preset (.wcp)
name My Pack
author me
key A minor
bpm 118
meter 4/4

progression "Verse"
  tags minor, driving
  minor true
  chords | i:4 | bVI:4 | bIII:4 | bVII:4 |
end

motif "Hook"
  tags hook, bright
  notes 0:0.75 2:0.75 c2:0.5 4:1.0@f 3:0.5 2:0.5
end

motif "Answer"
  steps 4 3 2 r 0
  dur   0.5 0.5 1.0 0.5 1.5
  dyn   mf mf mp mf p
end
