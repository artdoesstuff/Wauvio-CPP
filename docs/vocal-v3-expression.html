Vocal engine (wauvio/vocal)

v3 — Expression, ornaments and events

See it in action: Speech and non-lexical sounds · Make it expressive

Ornaments

make_ornament(name, dur, depth) returns a bend curve (semitones vs seconds from note start). Names: fall, doit, shakuri, scoop_in, kobushi, turn, trill, mordent. depth scales size; unknown names return an empty curve. Apply with NoteRef::ornament().

Humanisation and auto-expression

  • Humanize — timing, bias, length, pitch, tone (per-note random brightness/breathiness/mouth opening), entry (starting pitch error corrected within ≈90 ms), pressure (breath pressure sag over a phrase), phrase_gap (0.30 s), seed. All deterministic; different seeds are different “takes”. apply_humanize(), apply_pressure().
  • AutoExpr — switches vibrato (onset/fade/depth follow note length), dynamics (louder toward a phrase’s high point), phrase_end (longer fall and release on the last note), articulation (crisper consonants on fast notes); touches only fields still at Style defaults.
  • phrase_arc_shape(kind, u) — arch, crescendo, decrescendo, swell.

Speech intonation

speech_contour(kind, u) gives the sentence contour. accent_contour(morae, dur, nucleus, height_st = 3, declination_st = 1, mora_weighting) builds a Tokyo-type pitch-accent contour: nucleus 0 = heiban (L H H…), 1 = atamadaka (H L L…), n ≥ 2 = L H…H(n) L…; a nucleus beyond the last mora means accent on the last mora. Timing follows mora_cum(), exactly what the engine uses.

Events

Non-lexical vocal events are written as lyric tags — <kind[:variant][,intensity=0..1][,pitch=semitones][,key=value…]> — and expanded at render time into ordinary notes with pitch contours and lanes, so they are produced by the same voice. Kinds are available from event_kinds(): laugh, giggle, sob, hum/hmm, shout, kyaa, and interjections (ah, eh, un, fuun, uun, eeto, ano, waa, hya, hee, eee, maa).

  • Variants are lyric syllables for most kinds (they must parse to at least one mora). hum/hmm accept only “”, “hmm”, “hm?” and “mhm”; laugh/giggle also accept “kusu”.
  • parse_event_tag(tag, EventSpec&), is_event_tag(), diagnose_event(spec) (unknown kind/variant/parameter; empty = fine), expand_event(note, spec, seed). EventSpec::bad lists malformed parameters.
  • Use Singer::event(kind, midi, seconds, intensity, variant) or put the tag in a lyric (note_sec(69, 1.2, "<laugh>")).
