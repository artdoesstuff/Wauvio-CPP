Typical pipelines

  1. Score → WAV: Melody → Arrangement (instruments) → render().
  2. MIDI → WAV: load_midi (resolver, optional SF2) → optional setGenre → render().
  3. Produced mix: mixer_from_arrangement/mixer_from_midi → inserts, buses, sidechain, master chain → set_mastering → render() → fx::write_wav.
  4. Generated music: Composer (key, tempo, mood, genre) → ComposedSong → save(), save_midi, save_mastered.
  5. Effects: sfx::make(id) → set() → render(); compose with Layered.
  6. Vocals: Singer notes → render() or Ensemble → process_vocal.
