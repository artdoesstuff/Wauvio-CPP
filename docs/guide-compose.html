Guides & examples

Compose guide

The compose engine writes music for you. You choose a key, tempo, mood and (optionally) a genre, progression and motif; it generates chords, a melody, bass and drums, plays them with instruments from the music layer, and gives you a ComposedSong you can save as WAV or MIDI. The same seed always gives the same song. Include wauvio/compose.hpp (and compose/midi.hpp or compose/fx.hpp for MIDI export or mastering). Reference: Compose engine.

g++ -std=c++17 -O2 -I/path/to/wauvio-repo NAME.cpp -o NAME && ./NAME

1. A quick draft

One call produces a short multi-part draft. summary() prints what was generated, which is useful for learning how the pieces fit.

// The fastest path to music: pick a key, tempo and mood, and Wauvio composes a short draft with
// melody, chords, bass and drums, using a palette of instruments chosen for the mood.
#include "wauvio/compose.hpp"
#include <iostream>
using namespace wauvio::compose;

int main() {
    //                           root            scale                     BPM   mood            bars  seed
    ComposedSong draft = compose_draft(PitchClass::D, ScaleType::NaturalMinor, 124.0, Mood::Energetic, 8, 7);

    draft.save("compose_01_quick_draft.wav");        // render + write WAV
    std::cout << draft.summary() << "\n";           // what was generated (sections, chords, ...)
}

2. The Composer

Chain settings, then compose(). Choosing a mood also chooses instruments and drums; a genre restyles them. save_midi exports the notes and save_mastered renders through the mastering chain.

// The Composer: describe the song you want with chained settings, then compose().
// The same seed always produces the same song; change it for a different one.
#include "wauvio/compose/midi.hpp"       // compose::save_midi
#include "wauvio/compose/fx.hpp"         // compose::save_mastered
#include <iostream>
using namespace wauvio::compose;

int main() {
    ComposedSong song = Composer()
        .key(PitchClass::F, ScaleType::Major)
        .tempo(112.0)
        .meter(4, 4)
        .mood(Mood::Jazzy)                    // also picks the default instruments and drum pattern
        .genre("jazz", 0.75)                  // genre styling (see the Genre system); 0 = none, 1 = full
        .progression("Jazz Turnaround")       // a built-in progression (see the Compose reference for the list)
        .motif("Syncopated Hook")             // a built-in motif the melody is built from
        .accompaniment(AccompanimentPattern::Alberti)
        .bass_pattern(BassPattern::Walking)
        .seed(101)
        .compose();

    song.save("compose_02_composer.wav");
    save_midi(song, "compose_02_composer.mid");                                       // export the notes
    save_mastered(song, "compose_02_composer_mastered.wav",
                  wauvio::fx::master_for_genre("jazz"));                              // loudness-targeted master
    std::cout << song.summary() << "\n";
}

3. Song structure

Provide your own sections, each with a role, length in bars, energy, and switches for melody, chords, bass, drums and countermelody.

// Control the song structure yourself: an intro, verse, chorus and outro, each with its own
// length, energy and which parts play.
#include "wauvio/compose.hpp"
using namespace wauvio::compose;

static SectionSpec section(SectionRole role, const char* name, int bars, double energy,
                           const char* progression, const char* motif) {
    SectionSpec s;
    s.role = role; s.name = name; s.bars = bars; s.energy = energy;       // energy 0..1: how busy/loud
    s.progression = *find_progression(progression);                     // built-in names; returns nullptr if unknown
    s.motif       = *find_motif(motif);
    return s;
}

int main() {
    Composer c;
    c.key(PitchClass::A, ScaleType::NaturalMinor).tempo(104).mood(Mood::Melancholic).seed(5);

    SectionSpec intro = section(SectionRole::Intro, "Intro", 4, 0.3, "Jazz Turnaround", "Sigh Step");
    intro.enable_drums = false; intro.enable_bass = false;               // just chords and melody
    c.add_section(intro);
    c.add_section(section(SectionRole::Verse,  "Verse",  8, 0.55, "Jazz Turnaround", "Sigh Step"));
    c.add_section(section(SectionRole::Chorus, "Chorus", 8, 0.9,  "Jazz Turnaround", "Rising Triad"));
    SectionSpec outro = section(SectionRole::Outro, "Outro", 4, 0.25, "Jazz Turnaround", "Sigh Step");
    outro.enable_drums = false;
    c.add_section(outro);

    c.compose().save("compose_03_sections.wav");
}

4. Your own chords and motifs (.wcp)

A .wcp file is a small text format for progressions (Roman numerals) and motifs (scale steps), so you can reuse your musical ideas. Ten example packs ship in wauvio/compose/wcp/presets/. Format: WCP format.

// Bring your own harmony and motifs with a .wcp (Wauvio Compose Preset) text file.
#include "wauvio/compose.hpp"
#include <fstream>
#include <iostream>
using namespace wauvio::compose;

int main() {
    // A .wcp file is plain text. Write one (or edit it by hand). '#' starts a comment.
    std::ofstream("my_pack.wcp") << R"(# My pack
name My Pack
author me
key E minor
bpm 96
meter 4/4

progression "Verse"
  tags minor, moody
  chords | i:4 | VI:4 | III:4 | VII:4 |     # roman numerals; :N is the length in beats
end

motif "Hook"
  tags hook
  notes 0:0.75 2:0.75 c2:0.5 4:1.0@f r:0.5 3:0.5     # scale step:beats[@dynamic]; cN = Nth chord tone; r = rest
end
)";

    WcpBank bank; std::string err;
    if (!load_wcp("my_pack.wcp", bank, &err)) { std::cout << "bad file: " << err << "\n"; return 1; }
    std::cout << "loaded " << bank.progressions.size() << " progression(s), " << bank.motifs.size() << " motif(s)\n";

    ComposedSong song = Composer()
        .key(bank.key.root, bank.key.scale).tempo(bank.bpm).mood(Mood::Melancholic)
        .use_wcp(bank, "Verse", "Hook")          // use the pack's progression and motif
        .seed(3)
        .compose();
    song.save("compose_04_wcp.wav");

    // Shortcut: one call from a file.
    // compose_from_wcp("my_pack.wcp", "Verse", "Hook", Mood::Melancholic, 3).save("shortcut.wav");
}

5. The building blocks by hand

Everything the Composer does is available piece by piece: generate or write a progression, make a motif and develop it (transpose, invert…), turn them into a melody and countermelody, and play them with any instruments.

// The pieces under the Composer, used by hand: generate a progression, a motif and a melody,
// then play them with instruments of your choice.
#include "wauvio/compose.hpp"
#include <iostream>
using namespace wauvio;
using namespace wauvio::compose;

int main() {
    Key key(PitchClass::A, ScaleType::NaturalMinor);

    // 1. Harmony. Chords are Roman numerals resolved against a key.
    ProgressionOptions po; po.bars = 4; po.seed = 3; po.cadence = CadenceType::Half;
    ChordProgression prog = generate_progression(key, po);
    for (const ChordSymbol& c : prog.resolve(key)) std::cout << c.name() << " ";
    std::cout << "\n";

    // 2. A motif: a short idea described in scale steps (not fixed pitches), so it fits any key.
    MotifOptions mo; mo.contour = Contour::Hook; mo.length_beats = 4; mo.seed = 5;
    Motif hook = generate_motif(mo);
    Motif answer = invert(transpose(hook, 2));          // classic development tricks: transpose, invert, retrograde, ...

    // 3. A melody that follows the chords and develops the motif; plus a countermelody against it.
    MelodyOptions mel; mel.bpm = 100; mel.seed = 11; mel.form = PhraseForm::ABAC;
    music::Melody lead    = generate_melody(key, prog, hook, mel);
    music::Melody counter = generate_countermelody(key, prog, lead, 100.0);

    // 4. Play them like any other melody from the music layer.
    music::Arrangement a;
    instruments::SoloViolin violin; instruments::Flute flute; violin.reverb(); 
    a.add(violin, lead);
    a.add(flute, counter, 0.0, 0.6);
    a.limiter();
    render(a, "compose_05_building_blocks.wav");
    (void)answer;
}
