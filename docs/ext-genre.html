Music layer (wauvio/ext)

Genre system

Headers ext/genre/genre_types.hpp, genre_apply.hpp, genre_presets.hpp; namespace wauvio::music::genre. A genre preset is a bundle of per-role style rules that rewrite a melody and restyle an instrument.

Types

  • Role { Melodic, Bass, Percussion }.
  • RoleProfile — the style rules for one role:
GroupFields
Dynamicsvelocity_scale, velocity_floor, velocity_variance, accent_pattern (per-beat multipliers), downbeat_deemphasis
Timingswing_amount, timing_humanize_sec, quantize_grid_fraction, timing_offset_sec
Note shapingthin_probability (randomly drop soft notes), register_shift_semitones, force_articulation + articulation, fallback_gate_ratio
Timbrefilter_cutoff_mult, detune_cents_delta, stereo_width_override, noise_mix_delta, wobble_amount
Effectswant_reverb (+ room/wet/damping), want_chorus (+ rate/depth/wet), want_delay (+ time/feedback/wet), want_distortion (+ drive)
  • GenrePreset — name, description, tempo_scale, a default_profile and optional bass_profile / percussion_profile (set_bass(), set_percussion()); profile_for(role) falls back to the default. GenrePresetPtr is shared_ptr<const GenrePreset>.

Applying a preset

  • apply_to_melody(melody, preset, role, instrument = nullptr, seed = 1) mutates a Melody deterministically (hash-based randomness from seed): optionally thins soft notes, shifts register, forces an articulation (only if the instrument supports it), and scales each note's expression by the profile's velocity scale, accent pattern and variance, clamped between velocity_floor and 1. Timing fields (swing, humanize, quantize, offset) are not applied here; they are consumed by the MIDI layer — see MIDI genre.
  • style_instrument(instrument, preset, role) applies the role's timbre and effect wants; capture_style_baseline() / restore_style_baseline() snapshot and restore the instrument's gain, pan, effects and recipe so a preset can be undone.
