Music layer (wauvio/ext)

Genre system

Headers ext/genre/genre_types.hpp, genre_apply.hpp, genre_blend.hpp, genre_registry.hpp, genre_presets.hpp and genre_presets_extra.hpp; namespace wauvio::music::genre. A genre preset is a bundle of per-role style rules that rewrite a melody and restyle an instrument. There are 96 built-in genres, grouped into families, with a registry to find them by name.

See it in action: Genre styling · Find, blend and weaken genres
Quick use: auto p = genre::find("drum and bass"); then genre::apply_to_melody(melody, *p, genre::Role::Melodic, &instrument, seed, bpm); and genre::style_instrument(instrument, *p, genre::Role::Melodic);

Types

  • Role { Melodic, Bass, Percussion } and Family { Any, Guitar, Keys, Strings, Winds, Brass, Synth, Mallet, World, Vocal } (an instrument family, used to aim distortion).
  • RoleProfile — the style rules for one role:
GroupFields
Dynamicsvelocity_scale, velocity_floor, velocity_variance, accent_pattern (per-beat multipliers), downbeat_deemphasis, velocity_compress (0–1, pulls velocities toward a common level), groove_velocity (per-16th multipliers, repeating)
Timingswing_amount, swing_subdivision (2 = swing the eighths, 4 = the sixteenths), timing_humanize_sec, quantize_grid_fraction, timing_offset_sec, groove_timing (per-16th shifts in fractions of a 16th, + = late), gate_ratio (< 1 shortens every note)
Note shapingthin_probability (randomly drop soft notes), register_shift_semitones, force_articulation + articulation, fallback_gate_ratio
Timbrefilter_cutoff_mult, detune_cents_delta, stereo_width_override, noise_mix_delta, wobble_amount
Effectswant_reverb (+ room/wet/damping), want_chorus (+ rate/depth/wet), want_delay (+ time/feedback/wet), want_distortion (+ drive), distortion_family (restrict distortion to one instrument family, e.g. Guitar, so a rock preset no longer distorts strings and keys; Any = every instrument)

All new timing and feel fields default to “off”, so older presets behave exactly as before.

  • GenrePreset — name, description, tempo_scale, a default_profile and optional bass_profile / percussion_profile (set_bass(), set_percussion()); profile_for(role) falls back to the default. Registry metadata: family (e.g. “Rock”, “Electronic”, “Jazz & Blues”), aliases (other spellings, matched by find()) and bpm_min/bpm_max (typical tempo range, 0 = unknown). GenrePresetPtr is shared_ptr<const GenrePreset>.

Finding genres: the registry

auto p = wauvio::music::genre::find("drum and bass");   // nullptr if unknown
for (auto& g : wauvio::music::genre::all()) { /* every built-in preset */ }
wauvio::music::genre::add(my_preset);                    // your own presets join the same lookup
  • find(name) ignores case, spaces and punctuation and also matches aliases (“Drum & Bass”, “drum and bass” and “dnb” all work).
  • all(), names(), families(), in_family(family), for_bpm(bpm) (presets whose typical tempo range contains bpm), add(preset) (adds or replaces by name).
  • The registry and the extra presets are generated by wauvio/ext/genre/gen_genres.py (see Tools): edit its table and re-run it to add or change a genre.

Applying a preset

  • apply_to_melody(melody, preset, role, instrument = nullptr, seed = 1, bpm = 0.0) mutates a Melody deterministically (hash-based randomness from seed): optionally thins soft notes, shifts register, forces an articulation (only if the instrument supports it), and scales each note’s expression by the profile’s velocity scale, accent pattern and variance. Timing is applied only when you pass a bpm (a Melody has no tempo of its own): swing, quantise, groove, humanise, gate and the velocity groove/compression. Notes keep their order and the melody keeps its total length. The MIDI layer supplies the file’s tempo automatically.
  • style_instrument(instrument, preset, role) applies the role’s timbre and effect wishes; capture_style_baseline() / restore_style_baseline() snapshot and restore an instrument’s gain, pan, effects and recipe so a preset can be undone.

Blending and strength

  • blend(a, b, t) — t = 0 gives a, 1 gives b, in between every number is interpolated and effects fade in/out.
  • scaled(preset, strength) — 1 = the preset itself, 0 = none, 0.5 = halfway between neutral and the preset.
  • neutral() — the “no genre” preset (every profile at its defaults).

struct RoleProfile
    double velocity_scale    = 1.0;
    double velocity_floor    = 0.0;
    double velocity_variance = 0.0;
    std::vector<double> accent_pattern;
    double swing_amount             = 0.0;
    double timing_humanize_sec      = 0.0;
    double quantize_grid_fraction   = 0.0;
    double timing_offset_sec = 0.0;
    double downbeat_deemphasis = 0.0;
    double thin_probability = 0.0;
    int register_shift_semitones = 0;
    bool               force_articulation = false;
    wauvio::music::Articulation articulation      = wauvio::music::Articulation::Sustain;
    double             fallback_gate_ratio = 1.0;
    double filter_cutoff_mult    = 1.0;
    double detune_cents_delta    = 0.0;
    double stereo_width_override = -1.0;
    double noise_mix_delta       = 0.0;
    double wobble_amount         = 0.0;
    bool  want_reverb = false;
    float reverb_room = 0.5f, reverb_wet = 0.25f, reverb_damping = 0.5f;
    bool   want_chorus = false;
    double chorus_rate_hz = 0.5, chorus_depth_ms = 1.5;
    float  chorus_wet = 0.3f;
    bool   want_delay = false;
    double delay_time_ms = 250.0;
    float  delay_feedback = 0.3f, delay_wet = 0.25f;
    bool  want_distortion = false;
    float distortion_drive = 2.0f;
    // timing and feel (all default to "off", so older presets behave exactly as before)
    int    swing_subdivision = 2;            // 2 = swing the eighths, 4 = swing the sixteenths
    std::vector<double> groove_timing;       // per 16th step (repeats): shift in fractions of a 16th, + = late
    std::vector<double> groove_velocity;     // per 16th step (repeats): velocity multiplier
    double velocity_compress = 0.0;          // 0..1: pulls velocities toward a common level (pop/EDM loudness)
    double gate_ratio        = 1.0;          // < 1 shortens every note (the remainder becomes silence)
    // Restricts want_distortion to one instrument family (e.g. Guitar), so a rock preset no longer
    // distorts the strings and keys. Any = every instrument, the old behaviour.
    Family distortion_family = Family::Any;
