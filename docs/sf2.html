SoundFont (wauvio/sf2)

SoundFont (SF2) support

wauvio/sf2.hpp (directory wauvio/sf2/, namespace wauvio::sf2) loads SoundFont 2 files and exposes their presets as Wauvio instruments. It includes ext.hpp because it produces music::SampledInstruments.

Loading and using a SoundFont

#include "wauvio/sf2.hpp"
#include "wauvio/midi.hpp"
using namespace wauvio;

auto sf = std::make_shared<sf2::SoundFont>("GeneralUser.sf2");
for (auto& p : sf->list_presets()) { /* p.name, p.bank, p.program */ }

midi::track::LoadOptions opts;
opts.resolver.set_bank_provider(sf);     // SF2 presets win over built-in GM instruments
auto music = midi::track::load_midi("song.mid", opts);

SoundFont implements music::IBankProvider, so it plugs directly into the MIDI instrument resolver.

SoundFont class

  • SoundFont(path) — parses the file; throws Sf2ParseError (a std::runtime_error) on malformed data or if the file has no sample audio.
  • name(), list_presets() → PresetInfo {name, bank, program}.
  • has_preset(bank_msb, bank_lsb, program) / create_instrument(...) — lookup by bank MSB and program; the LSB argument is ignored. Returns nullptr if missing.
  • has_percussion_preset(...) / create_percussion_instrument(...) — the bank and note arguments are ignored: the first preset found in bank 128 (then bank 120) is used as the whole kit, built once and cached; zones inside it are selected by note.
  • create_instrument_by_name(preset_name) — exact preset-name match.

Presets become a SampledInstrument whose zones come from the preset/instrument zone hierarchy, using global-zone defaults and key/velocity ranges. All presets share one converted stereo sample buffer (shared_audio), so many instruments cost little extra memory. Audio is read as 16-bit samples.

class ByteReader
public:
    ByteReader(const unsigned char* data, size_t size) : data_(data), size_(size) {}
    size_t position() const noexcept { return pos_; }
    size_t remaining() const noexcept { return pos_ < size_ ? size_ - pos_ : 0; }
    bool eof() const noexcept { return pos_ >= size_; }
    void require(size_t n) const
    uint8_t u8() { require(1); return data_[pos_++]; }
    uint16_t u16le()
    uint32_t u32le()
    int16_t s16le() { return static_cast<int16_t>(u16le()); }
    int8_t s8() { return static_cast<int8_t>(u8()); }
    std::string fourcc()
    std::string fixed_string(size_t len)
    void skip(size_t n) { require(n); pos_ += n; }
    void seek(size_t absolute)
    const unsigned char* ptr() const noexcept { return data_ + pos_; }
    const unsigned char* base() const noexcept { return data_; }
    size_t size() const noexcept { return size_; }
