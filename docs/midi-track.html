MIDI layer (wauvio/midi)

Loading, rendering and writing

MidiMusic and MidiPart

Header midi/track/midi_music.hpp, namespace wauvio::midi::track.

  • ResolvedNote — absolute time t, dur, midi_note, dyn, articulation, expression, pitch_bend_semitones, pitch_bend_curve, glide_from_midi.
  • MidiPart — one playable part: name, source_track_index, channel, gm_program, bank_msb/bank_lsb, is_percussion, program_from_midi_file, instrument_pinned, instrument or drum_kit, and notes.
  • MidiMusic — parts, duration_seconds, initial_bpm, ticks_per_quarter, smpte_timing, source_path, time_signatures, key_signatures, raw_midi. Methods: part_count(), part(i), set_instrument<T>(i) / set_instrument(i, ptr), set_drum_kit(i, kit), pin_instrument(i) / unpin_instrument(i) (protects an instrument from genre instrumentation), setGenre(preset[, options]), clearGenre(), has_genre(), current_genre(), total_samples(sr), render_part(i, sr, total_len), render(sr).

Loader

load_midi(path, LoadOptions) in midi/track/loader.hpp.

LoadOptions fieldDefaultMeaning
resolver—InstrumentResolver used to assign instruments
honor_sustain_pedaltrueCC64 extends held notes until pedal release
honor_portamentotruePortamento on/off controller creates glides (glide_from_midi)
pitch_bend_range_semitones2.0Initial bend range (RPN changes update it per channel)
default_glide_time0.08Glide duration in seconds
retain_raw_miditrueKeep the ParsedMidiFile in MidiMusic::raw_midi

The loader tracks per-channel state (program, bank select, sustain, portamento, pitch bend, expression and volume CCs, RPN) and converts note-on velocity to Dynamics and expression.

Rendering

  • MidiMusic::render(sr) mixes all parts to a stereo buffer.
  • midi::track::render_to_buffer(music, RenderOptions) applies the render options.
  • wauvio::render(music, path, opts) writes a WAV.
  • render_stems(music, output_dir, opts) writes one WAV per part (filenames sanitised from part names) and returns the paths.
  • wauvio::play(music, sr) / play_async(music, sr) (midi/playback.hpp) render then play through the core playback API.

Writing MIDI

save_midi(const music::Arrangement&, path, ppq = 480) and save_midi(const MidiMusic&, path) in midi/track/midi_writer.hpp write Standard MIDI Files. The internal MidiTrackBuilder emits track name, tempo, program change, control change, note on/off events with VLQ delta times.
