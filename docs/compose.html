Compose engine (wauvio/compose)

Compose engine overview

The compose engine (wauvio/compose.hpp, directory wauvio/compose/, namespace wauvio::compose) writes music for you. You choose a key, tempo, mood and optionally a genre, chord progression and motif; it generates harmony, a melody, a countermelody, accompaniment, bass and drums, assigns instruments from the music layer, and returns a ComposedSong you can render to WAV, export to MIDI or master. It is deterministic: the same settings and seed always give the same song.

See it in action: A quick draft · The Composer

How it works

  1. Harmony — a chord progression in Roman numerals (built-in, generated, or from a .wcp file), resolved against a key.
  2. Motif — a short melodic idea written in scale steps, so it fits any key.
  3. Melody — a phrase generator develops the motif over the chords (phrase forms like AABA), with a climax point and a resolution on the tonic; a countermelody can answer it.
  4. Arrangement — accompaniment, bass and drum patterns are generated per section, with instruments picked for the mood.
  5. Genre (optional) — the genre system restyles instruments at a chosen strength.
  6. Output — a ComposedSong holding sections and a ready music::Arrangement.

Minimal example

#include "wauvio/compose.hpp"
using namespace wauvio::compose;

int main() {
    auto song = compose_draft(PitchClass::D, ScaleType::NaturalMinor, 124.0, Mood::Energetic, 8, /*seed=*/7);
    song.save("draft.wav");
}
Scope. The composer produces competent, structured, repeatable music from rules, not from a trained model. Expect idiomatic loops and phrases that you will usually want to edit, restyle (genre), or use as a starting point: its output is a normal Arrangement, so you can modify tracks before rendering.
