Vocal engine (wauvio/vocal)

Vocal engine overview

The vocal engine (wauvio/vocal/) is a formant/glottal-source singing and speech synthesiser for Japanese, built around the character Yune. It does not use samples: it models the voice (glottal source, vocal-tract formants, consonant articulation, pitch and expression) and renders it from notes with kana, romaji or phoneme lyrics. It exists in three generations that can coexist in one program.

Generations

GenerationNamespaceHeaderAdds
v1wauvio::vocal::v1vocal/v1.hppCore singer: kana/romaji lyrics, pitch curves with vibrato, portamento and scoops, a single built-in voice, MIDI-lyric loading, SingerInstrument
v2wauvio::vocal::v2vocal/v2.hppDirect upgrade of v1: voice profiles and personas, .wvc voicebanks, expression lanes, events (laugh, sob, …), speech (say), humanisation, natural(), auto-expression, phoneme input, mic model, 5 voices
v3wauvio::vocal::v3vocal/v3.hpp, vocal/v3_fx.hppStreaming render (VoiceStream), coarticulation and consonant loci, pitch accent, particles, Ensemble (harmonies, doubles), transposed()/doubled(), vocal FX chains, diagnostics, 7 voices

Kanji lyrics (ruby, dictionary, diagnostics) are available in all three generations; they are documented on Lyric input.

Choosing a generation

  • Include vocal/v1.hpp, v2.hpp or v3.hpp directly to use a specific generation; they can be included together.
  • vocal/v3_fx.hpp = v3 + wauvio/fx.hpp + the ready-made vocal chain.
  • wauvio/vocal.hpp defines wauvio::vocal::current as an alias for the latest generation, currently v3 (it includes vocal/v3.hpp and sets namespace current = v3). Use current to follow new releases, or name a generation explicitly to stay on it.

Dependencies

Each generation includes wauvio.hpp (core), ext/core/core.hpp (for music::Instrument, Articulation) and midi/core.hpp (the light MIDI file model, to read lyric tracks). v3’s FX chain additionally needs wauvio/fx.hpp, which is why it is a separate header.

Quick start (v3)

#include "wauvio/vocal/v3.hpp"
using namespace wauvio::vocal::v3;

Singer s;                         // default voice: Yune
s.set_tempo(120);
s.natural();                      // living-voice imperfections (voice's recommended strength)
s.auto_expression();
s.note(69, 480, "さ");
s.note(71, 480, "く");
s.note(72, 960, "ら");
s.save("sakura.wav");
