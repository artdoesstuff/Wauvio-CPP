theory.hpp — notes and frequencies

Namespace wauvio::theory.

  • midi_to_freq(int midi_note) → 440 · 2^((n−69)/12) (equal temperament, A4 = 440 Hz, MIDI 69).
  • theory::notes contains constexpr double frequencies named C0 … B9, with sharps spelled Cs, Ds, Fs, Gs, As (e.g. notes::Cs4, notes::A4 = 440.0), and REST = 0.0.

REST is meaningful to seq: frequencies below 1 Hz render as silence of the note's duration.

Full API listing

The note table is ~120 constants; see wauvio/core/theory.hpp. Flats are not defined: use the enharmonic sharp.
