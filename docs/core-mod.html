LFO

Enums: LFOShape { Sine, Triangle, Square, SampleHold } and LFOTarget { Pitch, Amplitude, FilterCutoff, Pan }. Fields: shape, target, rate_hz (4), depth (0.5), phase_off. tick(sample_rate) returns a value in [-1, 1]; modulate(sample_rate) returns it scaled by depth. SampleHold picks a new random value each phase wrap using a fixed internal seed, so it is deterministic. The target field is a label for the caller: the LFO does not itself modify any other object.

Automation

AutoPoint {time_sec, value}. auto_eval(points, t) linearly interpolates a time-sorted list (clamping before the first and after the last point; empty list returns 0).

FunctionEffect
apply_volume_automation(buf, points, sr)Multiplies a mono or stereo buffer by the interpolated curve.
apply_filter_automation(src, cutoff_points, Q, mode, sr)Runs an SVFilter whose cutoff follows the curve (floored at 20 Hz), recomputing coefficients every sample. Returns a new buffer.

wauvio::mod::class LFO

class LFO
public:
    LFOShape  shape     = LFOShape::Sine;
    LFOTarget target    = LFOTarget::Amplitude;
    double    rate_hz   = 4.0;    ///< Oscillation frequency
    double    depth     = 0.5;    ///< Modulation depth [0,1]
    double    phase_off = 0.0;    ///< Phase offset (radians)
    LFO() = default;
    LFO(LFOShape sh, LFOTarget tgt, double rate, double depth_)
        : shape(sh), target(tgt), rate_hz(rate), depth(depth_) {}
    /// Returns the current LFO value in [-1, 1].
    float tick(int sample_rate) noexcept
    /// Returns depth-scaled modulation value.
    float modulate(int sample_rate) noexcept
    void reset() noexcept { phase_ = 0.0; }
