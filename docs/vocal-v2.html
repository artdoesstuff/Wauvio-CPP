Vocal engine (wauvio/vocal)

v2 — differences from v1

Namespace wauvio::vocal::v2, header vocal/v2.hpp, sources in vocal/yune-v2/. v2 is a direct upgrade of v1: the same synthesiser and the same Singer/NoteRef shape, extended with voice profiles and a layer of expression controls. It is not the current engine: v3 reworks the articulation and adds streaming and ensembles, and is the one to use for new work. This page lists only what v2 changes relative to v1.

Reading guide. The concepts v2 introduced (Style expression fields, personas, lanes, events, .wvc voicebanks) are documented in full on the v3 pages, since v3 keeps them. Links below point there; each item is marked as introduced in v2.

Compatible with v1

  • Same Singer score-building API (note, note_sec, note_at, rest, style(), parse_options(), seed, phrase_pitch_curve, MIDI loading, render/render_stereo/save) and the same NoteRef setters.
  • All new Style fields default to “off”, so a default Style renders as v1 does.
  • Same limits as v1: a NoteRef is valid only until the next note is added (notes are in a std::vector), and there is no streaming render.

Added in v2

Voices

  • Voice profiles. v1 has one hard-wired voice; v2 adds VoiceProfile (model, default look, lyric defaults, personas, recommended natural strength), Singer::set_profile() and a Singer(VoiceProfile) constructor. Singer() defaults to Yune. SingerInstrument gains a profile member (replacing v1’s voice_model). See Voices, personas and voicebanks.
  • Five built-in voices: yune, yune-old, reiha, koharu, itsuki (v3 later adds mio and akari).
  • .wvc voicebanks — export/load voices as text (save_profile, load_profile, make_voice); shipped in yune-v2/voicebanks/.
  • Personas — named, bounded variations of a voice’s look (PersonaLibrary, Singer::persona, persona_blend, persona_lane, per-note persona/persona_morph).
  • VoiceModel changes: name becomes a std::string, and the engine gains per-voice gains in a Tune struct (out_scale, asp_gain, fric_gain, upper_gain, sing_gain, air_gain, pre_gain, f23_gain), so voices tune independently and rendering is thread-safe.

Expression

  • New Style fields (Style): formant_shift, mouth_open, growl, tremor/tremor_rate, fry, air, reg/reg_auto, glottal_onset, pitch_loud, pitch_snap, undershoot, porta_interval, exit_fall_min, bidakuon, n_nasalize, mumble, transition_speed, vv_glide, devoice_max, mora_weighting, glottal_final, grit, natural. In v2, n_nasalize and mora_weighting default to 0 (off).
  • Automation lanes (lane, per note and Singer-wide) over named channels, plus phrase_arc.
  • NoteRef additions: growl, tremor, fry, breathy, falsetto, formant_shift, mouth_open, hard_onset, ornament, lane, persona, persona_morph.
  • Humanisation: humanize(), natural(), auto_expression() (Expression).
  • Ornaments: fall, doit, shakuri, scoop_in, kobushi, turn, trill, mordent.
  • Mic model (mic.hpp): proximity, air, de-esser, mouth noise.

Speech and events

  • Singer::say() — spoken utterances with intonation contours (statement, question, flat, trail, emphatic, ne, yo, ka, no). v2 has no pitch-accent argument.
  • Events (event() and <tag> lyrics): laugh, giggle, sob, hum, shout, kyaa and interjections.

Lyrics

  • Phoneme input {k a n a} with *strength and @weight overrides, time weights さ[0.7]ん[0.3], the cute parse option, and the [ŋ] sound (ng) (Lyric input).

Diagnostics and tools

  • Singer::diagnostics().
  • New tools/voice_tool.cpp and tools/listen.cpp; sing_score gains the score commands for the new features (Tools).

Still not in v2 (added by v3)

Streaming render (VoiceStream), Ensemble, transposed()/doubled(), consonant locus equations and coarticulation, Tokyo pitch accent in say(), the particles option, the [v] consonant, the new vibrato controls (vib_am, vib_shape, vib_accel), the FX chain, extra voices, and a stable NoteRef (std::deque storage). See the overview for the full comparison.

API listing (files new or changed in v2)

Declarations for the v2 headers that did not exist in v1, plus the changed singer.hpp. Unchanged-in-spirit files (japanese, pitch, synth) are in the v1 listing and the v3 pages.
