Instrument (abstract)

Subclasses implement StereoBuffer render_note(const Note&, int sample_rate) and may override supported_articulations() (supports(a) queries it). Common members: name, gain, pan, and an optional per-instrument effect chain. Convenience: play(midi, duration, dyn, art), play(Note), play_chord(Chord).

The chain is enabled by chainable setters and applied after the note is rendered, in this fixed order: distortion (soft clip) → EQ → chorus → delay → reverb, each channel processed independently using copies of the stored effect objects:

SetterDefaults
reverb(room_size, wet, damping)0.6, 0.3, 0.5
chorus(rate_hz, depth_ms, wet)0.5, 1.5, 0.4
delay(time_ms, feedback, wet)250, 0.35, 0.3
eq(ParametricEQ)—
distortion(drive)2.0

InstrumentPtr is std::shared_ptr<Instrument>. IBankProvider is an abstract interface for preset sources (used by the SF2 loader and MIDI resolver): has_preset/create_instrument by bank MSB/LSB/program and has_percussion_preset/create_percussion_instrument by GM note.

Track and Arrangement

Track references an instrument (non-owning) and holds notes and chords in order: add(Note), add(Melody), add_chord(Chord), rest(d), total_duration(), render(), plus read accessors (entry_count, entry_note, entry_chord, entry_is_chord, entry_onsets).

Arrangement owns tracks with start offsets and gains: tempo, time_signature, add(instrument, melody, start_time, track_gain) (returns the new Track&), add_track(track, start, gain), chainable master options limiter(threshold = 0.9) and master_reverb(room, wet), introspection (track_count, track_at, start_time_at, gain_at, has_limiter, …) and render() returning a stereo buffer. Note durations are in seconds; Tempo is provided as a helper rather than being applied automatically to Note::duration.

struct Note
    int          midi_note   = 60;
    double       duration    = 0.5;
    Dynamics     dynamics    = Dynamics::mf;
    Articulation articulation = Articulation::Sustain;
    double       pan         = 0.0;
    double       expression          = 1.0;
    double       pitch_bend_semitones = 0.0;
    int          glide_from_midi     = -1;
    double       glide_time          = 0.08;
    std::vector<std::pair<double,double>> pitch_bend_curve;
    double       mod_wheel   = 0.0;
    double       aftertouch  = 0.0;
    Note() = default;
    Note(int midi, double dur, Dynamics dyn = Dynamics::mf,
         Articulation art = Articulation::Sustain, double p = 0.0)
        : midi_note(midi), duration(dur), dynamics(dyn), articulation(art), pan(p) {}
    bool is_rest() const noexcept { return midi_note < 0; }
    double bend_at(double t) const
