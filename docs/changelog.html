Changed behaviour

  • wauvio::vocal::current now aliases v3 (it used to alias v2).
  • env::DAHDSR::apply: the default note-off is never earlier than half the note, and a note-off during the attack or decay releases from the level actually reached. See env.
  • Genre timing in the music layer: apply_to_melody takes an optional bpm and then applies swing, groove and humanise itself (the MIDI layer already did).
  • Tuned percussion sounds differ (modal rather than FM), so renders using xylophone, vibraphone and similar instruments will sound different.
  • The voice registry (voices_registry.hpp) is now generated; voices.hpp only includes it.

Notes

  • The additions are additive; the behaviour changes are listed above. All guide examples from the previous docs were re-run against the new source and still compile and produce audio.
  • The new archive does not contain a LICENSE file; the earlier one did (GPL-3.0). Add it back to the repository.
