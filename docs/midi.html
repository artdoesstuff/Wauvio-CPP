MIDI layer (wauvio/midi)

MIDI layer overview

The MIDI layer (wauvio/midi.hpp, directory wauvio/midi/) reads Standard MIDI Files, resolves each track to a Wauvio instrument, optionally restyles the performance with a genre preset, and renders or writes MIDI. It builds on the music layer (wauvio/ext.hpp).

Include structure

  • midi/core.hpp includes only core/common.hpp plus the file model. It is deliberately light: the Yune vocal engines include it just to read a .mid score.
  • wauvio/midi.hpp includes the full stack in order: core model, GM map, resolver, midi_music, genre, genre presets, loader, render, writer, playback.

Typical workflow

#include "wauvio/midi.hpp"
using namespace wauvio;

midi::track::LoadOptions opts;
opts.resolver.override_channel(0, [] { return std::make_shared<instruments::SoloViolin>(); });
auto music = midi::track::load_midi("song.mid", opts);

music.setGenre(midi::genre::presets::jazz());   // optional restyle (reversible)
music.set_instrument<instruments::Harp>(2);      // swap one part

render(music, "song.wav");                      // RenderOptions defaults
play(music);                                    // blocking playback (midi/playback.hpp)
