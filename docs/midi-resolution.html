Instrument resolution and General MIDI map

InstrumentResolver

Header midi/resolution/instrument_resolver.hpp. Decides which Instrument plays a part. InstrumentFactory is std::function<InstrumentPtr()>. Register overrides with:

  • override_channel(channel, factory)
  • override_bank_program(msb, lsb, program, factory)
  • override_program(program, factory)
  • override_percussion_note(note, factory)
  • set_bank_provider(shared_ptr<IBankProvider>) — plug in e.g. an SF2 bank.
  • clear_overrides()

Resolution order, melodic (resolve_melodic(channel, program, bank_msb, bank_lsb)): channel override → exact bank/program override → bank provider (if it has the preset) → program override → built-in General MIDI instrument.

Resolution order, percussion (resolve_percussion(channel, gm_note, …)): channel override → bank provider → percussion-note override → built-in GM percussion instrument. Channel index 9 (MIDI channel 10) is percussion (is_percussion_channel).
