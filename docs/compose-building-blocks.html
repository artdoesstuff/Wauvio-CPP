Compose engine (wauvio/compose)

Keys, chords, progressions, motifs and melodies

The pieces beneath the Composer, usable on their own. See example 5.

See it in action: The building blocks by hand

Key, scale and pitch class (compose_common.hpp)

  • PitchClass: C, Cs/Db, D, Ds/Eb, E, F, Fs/Gb, G, Gs/Ab, A, As/Bb, B (0–11). parse_pitch_class("Bb", out), pitch_class_name(pc, prefer_flats), wrap_pc.
  • ScaleType: Major, NaturalMinor, HarmonicMinor, MelodicMinor, Dorian, Phrygian, Lydian, Mixolydian, PentatonicMajor, PentatonicMinor, Blues, WholeTone. scale_intervals, parse_scale_type("natural_minor", out), is_minor_scale.
  • Key{root, scale}: degree_midi(degree, octave, chromatic), degree_pc, is_in_scale(midi), snap_to_scale(midi), midi_to_step(midi, base_octave), name(). Meter{beats_per_bar, beat_unit} with bar_beats(). beats_to_seconds(beats, bpm).
  • Rng — seeded generator (uniform, bipolar, range, range_int, chance, pick, weighted_index) behind all generation. ComposeError (std::runtime_error) is thrown for invalid input.

Chords (harmony.hpp)

ChordQuality: Major, Minor, Diminished, Augmented, Sus2, Sus4, Major7, Minor7, Dominant7, HalfDim7, Dim7, MinMaj7, Add9, Maj9, Min9, Dom9, Power5. A RomanChord (degree, accidental, quality, inversion, duration_beats, secondary_of) is resolved against a key into a ChordSymbol (root, quality, bass, duration; pitch_classes(), tones_in_range(), nearest_chord_tone(), name()) with resolve_chord(rc, key). voice_lead(prev, chord, low, high, voices) and voice_lead_progression(chords, …) choose smooth voicings.

Roman-numeral chord syntax

Used by parse_roman_chord and in .wcp files. Form: [accidentals]NUMERAL[suffix][^inversion][/target][:beats].

PartMeaningExamples
NumeralI–VII; upper case = major, lower case = minorI vi V
Accidentalsb flat or # sharp, before the numeralbVII bIII
Suffixmaj7/M7, 7, m7, m7b5/hdim7, dim/o/°, dim7, aug/+, sus2, sus4, maj9, 9, m9, add9, 5, mImaj7 ii7 V7 vii° I5
Inversion^0–^3I^1
Secondary/numeral: chord of another degreeV7/vi
Length:beats (default one bar)IV:2

A suffix-less lower-case numeral is minor and a bare 7 on a lower-case numeral is a minor 7th; on an upper-case numeral it is a dominant 7th.

Progressions (progressions.hpp)

  • ChordProgression — name, description, tags, minor_bias, chords; total_beats(), resolve(key) → ChordSymbols, chord_index_at_beat(beat). make_progression(name, tokens, default_beats, minor_bias, tags, desc) builds one from Roman-numeral tokens.
  • generate_progression(key, ProgressionOptions) — bars 4, beats_per_bar 4, harmonic_rhythm_beats 4, complexity 0.35 (higher = more 7ths and colour chords), cadence (Authentic, Half, Plagal, Deceptive, Loop), start_on_tonic true, seed.

Motifs (motifs.hpp)

A Motif is a list of MotifNotes: scale step (relative to the key, so it transposes automatically) or a ChordTone basis (the Nth tone of the current chord), optional chromatic shift, duration_beats, rest flag, dynamics and articulation.

  • Development: transpose(m, steps), invert(m, pivot), retrograde(m), scale_rhythm(m, factor), sequence(m, repetitions, step_per_repeat), vary_motif(m, rng, amount).
  • generate_motif(MotifOptions) — length_beats 4, contour (Arch, Ascending, Descending, Wave, Pendulum, Hook), density 0.55, syncopation 0.25, rest_prob 0.12, range_steps 5, seed.
  • builtin_motifs() and find_motif(name):

Melody generation (melody_gen.hpp)

  • generate_melody(key, progression, seed_motif, MelodyOptions) → music::Melody. Options: low_midi/high_midi (60–81), motif_adherence 0.75, chord_tone_strength 0.85, passing_tone_prob 0.30, climax_pos 0.72 (fraction through the phrase), resolve_on_tonic true, form (PhraseForm: AABA, ABAC, AA_Prime, AABB, Through), bpm, beats_per_bar, seed.
  • generate_countermelody(key, progression, lead, bpm, low, high, seed) — a complementary line against an existing melody (defaults 55–74).
  • realize_motif_span(…) — the lower-level step that places a motif over a stretch of the progression.

wauvio::compose::class Rng

class Rng
public:
    explicit Rng(uint64_t seed = 1) noexcept { reseed(seed); }
    void reseed(uint64_t seed) noexcept
    uint64_t next() noexcept
    double uniform() noexcept { return static_cast<double>(next() >> 11) * (1.0 / 9007199254740992.0); }
    double bipolar() noexcept { return uniform() * 2.0 - 1.0; }
    double range(double a, double b) noexcept { return a + (b - a) * uniform(); }
    int    range_int(int lo, int hi) noexcept
    bool   chance(double p) noexcept { return uniform() < p; }
    template <typename T>
    const T& pick(const std::vector<T>& v)
    size_t weighted_index(const std::vector<double>& weights) noexcept
