Overview

Wauvio documentation

Wauvio is a header-only C++17 audio engine: oscillators and synthesis, a music layer with hundreds of modeled instruments, a full effects and mastering suite, MIDI loading and rendering, SoundFont playback, a sound-effect designer with a 190-preset catalog, and a Japanese singing-voice synthesiser. This site documents every part of the engine.

Start here

  • Getting started — requirements, including headers, compiling, first sounds.
  • Concepts for beginners — the handful of ideas behind everything, plus troubleshooting.
  • Guides with runnable examples: Core, Music layer, FX, MIDI & SoundFont, SFX, Vocal.
  • Showcases — listen to what Wauvio can do.
  • Architecture — modules, namespaces and how they depend on each other.

About this documentation

The guides contain 39 complete example programs (downloadable from the examples/ folder), each compiled and run against this version of the source. The reference pages were written from the C++ sources. Each combines explanation with a Full API listing that is extracted directly from the headers (public declarations and their comments), so the signatures are exact. The SFX catalog was generated by compiling the headers and reading the live preset registry.
