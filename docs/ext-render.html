See it in action: Output options

RenderOptions

FieldDefaultMeaning
sample_rate44100Output rate written to the file
channels2Channel count
bit_depth1616, 24 or 32 (32 is IEEE float). Other values throw std::runtime_error
normalize, normalize_peaktrue, 0.95Peak-normalise the final mix
ditherDitherType::NoneNone or Triangular
render_tail_sec0Silence appended so effect tails are not cut off
loop_count1Repeat the rendered audio N times
interpolationLinearSample-playback interpolation
worker_threads00 = auto-resolve worker count
deterministic_seed_enabled, seedfalse, 0Seed dither noise for reproducible output

Functions

  • apply_render_options(buf, opts) — tail, then loop, then normalise, then clamp.
  • render(StereoBuffer, path, opts) and render(Arrangement, path, opts) — apply options and write a WAV.
  • music::render_to_buffer(arrangement, opts) — returns the processed buffer without writing a file.
