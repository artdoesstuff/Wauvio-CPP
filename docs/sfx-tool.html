SFX engine (wauvio/sfx)

wauvio_sfx_tool (command line)

Source: wauvio/sfx/tools/wauvio_sfx_tool.cpp. Build with:

g++ -std=c++17 -O2 -I<repo root> wauvio/sfx/tools/wauvio_sfx_tool.cpp -o wauvio_sfx_tool

Commands

CommandDescription
list [--category C] [--search TEXT]List presets
categoriesList categories with counts
search TEXTSearch ids, names, tags and descriptions
info IDDescription, parameters and defaults of one preset
render IDRender one preset
render-category CATRender every preset of a category
render-allRender the whole catalog
catalogPrint the catalog as Markdown
help, --help, -hPrint usage

Options

OptionMeaning
--out DIROutput directory (default sfx_out)
--seed NSeed (≥ 0)
--sr HZSample rate
--monoMono output
--peak DBNormalisation peak
--duration SEC | --beats NLength in seconds or beats
--tempo BPMTempo
--set NAME=VALUESet any parameter (repeatable)
--intensity, --brightness, --pitch, --tail, --widthShortcuts for common parameters

Rendering writes DIR/<category>/<id>.wav and DIR/manifest.json. Exit status: 0 success, 1 if any render failed, 2 usage error.
